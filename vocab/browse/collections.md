# Collections

A *collection* is a labelled group of related concepts, declared with
`skos:Collection`. Membership carries **no** broader/narrower meaning: a
concept's place in the [hierarchy](../hierarchy/) is independent of the
collections it belongs to. Collections are the usual way to represent facets,
or node labels in a thesaurus.

Each collection's description says what decides membership, and each is listed
with its members. Collections have URIs in the same namespace as concepts, so
every one of them dereferences on its own.

`skos:member` has no inverse in SKOS, so the statement lives only on the
collection — which is why a term's own page and [All terms](../all/) both
repeat it from this side.
