# Resources

Related documentation, specifications, and reading.

## Standards this namespace builds on

Used by the vocabulary as published:

- [SKOS](https://www.w3.org/TR/skos-reference/) — Simple Knowledge Organization System
- [ISO 25964 SKOS extension](http://purl.org/iso25964/skos-thes#) — `broaderGeneric`,
  `broaderPartitive`, and `broaderInstantial`, which say *how* one concept is broader
  than another. They are sub-properties of `skos:broader`, so the build materialises
  the plain `skos:broader` alongside them for consumers that do no reasoning.
- [Dublin Core Terms](https://www.dublincore.org/specifications/dublin-core/dcmi-terms/) —
  titles, dates, provenance, licensing
- [VANN](https://vocab.org/vann/) — declares the preferred prefix (`pkmv`) and
  namespace URI inside the vocabulary itself, so a consumer does not have to guess
- [PROV-O](https://www.w3.org/TR/prov-o/) and [FOAF](http://xmlns.com/foaf/0.1/) —
  typing the people and software in [agents](../agents/)
- [VoID](https://www.w3.org/TR/void/) — Vocabulary of Interlinked Datasets, in
  [`void.ttl`](../void.ttl)

Used by parts of the namespace still in development:

- [OWL 2](https://www.w3.org/TR/owl2-overview/) — Web Ontology Language
- [SHACL](https://www.w3.org/TR/shacl/) — Shapes Constraint Language
- [JSON-LD 1.1](https://www.w3.org/TR/json-ld11/) — JSON for Linked Data
- [LinkML](https://linkml.io/) — schema modeling used for the shape artifacts
- [SKOS-XL](https://www.w3.org/TR/skos-reference/skos-xl.html) — reified labels, if
  labels ever need their own provenance or relationships
