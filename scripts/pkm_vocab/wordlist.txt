# the vocabulary already says about itself.

# `/usr/share/dict/web2` is a 1934 Webster's, so it knows "interoperability"
# and not "workflow". Everything below was measured against the real export
# rather than guessed: each entry is a word that actually appears in a note and
# is actually correct.
#
# Lowercase entries are prose words, matched through the same suffix morphology
# as the dictionary -- "workflow" covers "workflows", "timestamp" covers
# "timestamped" and "timestamps". Capitalised entries are CamelCase tokens,
# matched case-insensitively; they are external product names, which read as
# citations but are not terms in this vocabulary.
#
# Add a word only after checking it is not a typo. `mispelling` is deliberately
# absent: it was the one real misspelling in the change notes, this check found
# it, and 0.1.8 fixed it in the editor. Allowlisting it would have hidden it.
