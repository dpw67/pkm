# PKM Taxonomy

**Concept scheme:** `https://w3id.org/pkm/taxonomy`

Hierarchical (`skos:broader` / `skos:narrower`) structure over the concepts defined in
the [vocabulary](../vocab/). This scheme carries only relationships — definitions are
authored once, in the vocabulary.

## Download

- [`pkm-taxonomy.ttl`](pkm-taxonomy.ttl) — Turtle

## Hierarchy

- **note**
  - permanent note — refined into a durable, self-contained idea
  - literature note — an idea from an external source, in the reader's own words
  - fleeting note — a quick capture not yet processed
