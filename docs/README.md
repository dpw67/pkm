# Documentation

This is a guide that tells you what you need to know and do 
for accessing, using, and integrating the **PKM Vocabulary**. 

It highlights the fastest way in, what you can do with it, 
details about concepts and collections, and how you can integrate 
with apps, tools, and databases in your environment.

## Getting Started
Access the persistent URI namespace for 
Personal Knowledge Management (pkm) at **https://w3id.org/pkm**, 
which contains the PKM vocabulary, taxonomy, ontology, 
knowledge graph, resources, and examples. 

During this initial stage, the primary focus is the vocabulary, 
concepts, and collections created with the SKOS Editor. This will 
evolve into an entire ontology pipeline over time as this 
is developed further (from concepts to agents).

Visit these companion websites to learn more about the PKM Vocabulary.

- [PKM Vocabulary](https://w3id.org/pkm/vocab)
- [Notes (Obsidian)](https://notes.warrenweb.net/pkm/vocab)
- [Blog (Ghost)](https://blog.warrenweb.net/three-places-for-one-pkm-vocabulary)

### SKOS (Simple Knowledge Organization System)
If you are interested in learning more about SKOS, 
visit the following primer and reference guide.

- [SKOS Primer](https://www.w3.org/TR/skos-primer/)
- [SKOS Reference](https://www.w3.org/TR/skos-reference/)

### SKOS Editor
To learn more about the SKOS Editor used to develop the PKM Vocabulary, 
visit the following GitHub repository. Jessica Talisman developed this 
tool and shared it with the community. You can explore the code and 
documentation to learn more about how it works, including the 
architecture and user interface. For example, you might want to 
import my PKM Vocabulary into the SKOS Editor to explore the 
concepts, collections, and relationships.

- [Intentional Arrangement SKOS Editor](https://github.com/jesstalisman-ia/intentional-arrangement-skos)
