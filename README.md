# pkm
This is a persistent URI namespace at http://w3id.org/pkm
with resources on Personal Knowledge Management (PKM)
for the Knowledge System Architecture (KSA) project,
which integrates:
- Obsidian linked notes (Markdown/YAML),
- Neo4j graph database (Cypher)
- Claude AI (Sonnet LLM)
- Diabetes data (Dexcom and Glooko websites)
- Python
- Swift

It includes documentation of the following:
- vocabulary: SKOS terms with definitions (glossary)
- taxonomy: SKOS concepts and relationships
- ontology: RDF/OWL things (classes, instances, properties, and relationships)
- knowledge graph: Neo4j (Cypher): nodes, relationships, and properties
- tools: Python and Swift apps, services, scripts, intents, Siri
- resources: realted information and documentation
